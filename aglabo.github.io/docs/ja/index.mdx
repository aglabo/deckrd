**deckrd** は Claude Code 向けのドキュメント駆動フレームワークです。AI との対話を通して、
ゴールから要件・仕様・実装計画・実行可能なタスクまでを順に導き出します。

:::note
ドキュメントは `docs/` からこのサイトへ移行中です。
:::
