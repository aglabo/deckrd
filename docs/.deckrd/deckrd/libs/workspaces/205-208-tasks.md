## 進め方

1. RGR 必須のタスクは `temp/tasks/` に当該タスク分のみのチェックリストを作る
2. `/bdd-coder:bdd-coder` に 1 件ずつ委譲する（`deckrd-rule-bdd-cycle.md` の「1 委譲 = 1 タスク」）
3. 委譲直後に `git status --short` と `git diff --stat HEAD` で変更範囲を検証する。自己申告は根拠にしない
4. 想定外のファイルが変更されていたら次を委譲せずユーザーに報告する
5. RGR 免除のタスクは bdd-coder を通さず直接編集し、品質ゲートで検証する
6. コミット単位はタスク 1 件につき 1 コミットとする
7. テストとリントは `pnpm run` 経由で実行する。`runners/run-*.sh` を直接叩かない（`deckrd-rule-runners.md`）
